# 💰 FinanceFlow

**FinanceFlow** é uma aplicação web moderna para controle de finanças pessoais, desenvolvida com **Flask**, **SQLite**, **HTML/CSS/JS** e **Chart.js**.  
Ela permite que os usuários monitorem suas receitas, despesas, e obtenham uma visão clara e organizada de sua vida financeira.

---

## 🚀 Funcionalidades

- ✅ Registro e login de usuários
- 📊 Dashboard personalizada com gráficos de transações (Chart.js)
- 🌓 Modo escuro e visual moderno
- 📁 Exportação de transações em PDF
- 🖼️ Imagem de perfil do usuário
- 🔒 Acesso restrito à dashboard (só após login)
- 🧠 Backend com Flask + Banco de dados SQLite

---

## 🛠️ Tecnologias usadas

- **Python 3**
- **Flask**
- **SQLite**
- **HTML5, CSS3 e JavaScript**
- **Chart.js**
- **Jinja2 (templating)**
- **WeasyPrint (ou similar) para exportação em PDF**

---

## ⚙️ Como rodar o projeto localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/financeflow.git
cd financeflow
```

2. Crie e ative um ambiente virtual:

```bash
python -m venv venv
source venv/bin/activate  # no Windows use: venv\Scripts\activate
```

3. Instale as dependências:

```bash
pip install -r requirements.txt
```

4. Rode a aplicação:

```bash
flask run
```

Acesse em: [http://localhost:5000](http://localhost:5000)
