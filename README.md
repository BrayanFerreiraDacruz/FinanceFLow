# 📊 FinanceFlow — Gestão Financeira Inteligente

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Flask-2.x-000000?logo=flask&logoColor=white)](https://flask.palletsprojects.com/)
[![SQLite](https://img.shields.io/badge/SQLite-3.x-003B57?logo=sqlite&logoColor=white)](https://www.sqlite.org/)
[![Chart.js](https://img.shields.io/badge/Chart.js-FF6384?logo=chartdotjs&logoColor=white)](https://www.chartjs.org/)

O **FinanceFlow** é uma aplicação web de controle financeiro pessoal desenvolvida para oferecer clareza e controle sobre sua vida financeira. O foco do projeto é unir uma experiência de usuário (UX) fluida com visualizações de dados poderosas, permitindo decisões financeiras mais inteligentes.

---

## 📈 Funcionalidades de Alto Impacto

- **Painel de Controle Dinâmico:** Dashboards interativos que transformam números em insights visuais usando **Chart.js**.
- **Gestão de Transações:** Fluxo intuitivo para registro de receitas e despesas com categorização inteligente.
- **Relatórios Profissionais:** Exportação de dados em **PDF** para análise detalhada e histórico offline.
- **Segurança e Privacidade:** Sistema de autenticação robusto com criptografia de senhas e proteção de sessão.
- **Interface Adaptável:** Design responsivo com suporte completo a **Modo Escuro (Dark Mode)**.

---

## 🛠️ Stack Tecnológica

- **Backend:** Python com o framework Flask.
- **Banco de Dados:** SQLite, escolhido pela sua eficiência e portabilidade.
- **Frontend:** HTML5, CSS3 moderno e JavaScript puro.
- **Visualização de Dados:** Chart.js para gráficos de pizza, barras e linhas.
- **Geração de PDF:** ReportLab.

## ⚙️ Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/BrayanFerreiraDacruz/FINANCEFLOW.git
   ```
2. **Configure o ambiente virtual:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # No Windows: venv\Scripts\activate
   ```
3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Inicie o banco de dados:**
   ```bash
   python init_db.py
   ```
5. **Rode a aplicação:**
   ```bash
   flask run
   ```
